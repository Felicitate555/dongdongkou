# 动动口部署手册

本项目分两种互相隔离的运行方式：本机模式可选控制当前电脑；公网模式只服务网页演示，并由后端强制禁止宿主机鼠标与键盘 API。

## 本机使用

Windows 10/11、Python 3.10+：

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
python run.py
```

默认地址为 `http://127.0.0.1:8787`，系统控制关闭。只有确认页面来自本机后才启用：

```powershell
$env:DDK_DEPLOYMENT_MODE = "local"
$env:DDK_SYSTEM_CONTROL = "1"
python run.py
```

`DDK_SYSTEM_CONTROL` 不会把公网部署切成本机模式。要关闭本机控制，清除该环境变量并重启服务。

## Aliyun ECS 公网网页演示

### 1. 安全组与域名

- 将域名 A 记录指向 ECS 公网地址。
- 安全组只开放 SSH、HTTP、HTTPS；不要开放应用端口 `8787`。
- 在 ECS 安装 Docker Engine、Docker Compose 插件、Nginx 和 Certbot，并为域名签发 TLS 证书。
- 摄像头仅可在 HTTPS 或 `localhost` 来源使用。
- 服务校验 Host，只接受 `DDK_ALLOWED_HOSTS` 列出的域名；默认包括 `dongdongko.fun`、`localhost` 和回环地址。

### 2. 构建应用

把项目复制到服务器，按需配置环境变量：

```bash
cp .env.example .env
nano .env
# QWEN_API_KEY=你的 MiMo 密钥（可选）
docker compose up -d --build
docker compose ps
```

Dockerfile 和 Compose 固定使用 `DDK_DEPLOYMENT_MODE=public`；鼠标与键盘 API 即使遇到开启开关也仍返回 403。应用只映射到 ECS 自身的 `127.0.0.1:8787`，由 Nginx 接入。Uvicorn 只信任回环地址的代理头，不信任任意来源的 `X-Forwarded-*`。

### 3. 启用 Nginx HTTPS 反向代理

复制 `deploy/nginx-dongdongkou.conf` 到 Nginx 配置目录，确认 `dongdongko.fun` 的证书路径，再检查并重载：

```bash
sudo nginx -t
sudo systemctl reload nginx
curl -fsS https://你的域名/api/health
```

确认响应包含 `"deployment_mode":"public"` 和 `"system_control":false`。网页可以公开试用；来访者的摄像头画面在浏览器本地处理，页面交互只作用于网页内容。

### 4. MiMo 密钥

将 `QWEN_API_KEY` 写在服务器 `.env`。不要把真实密钥写入 Dockerfile、Compose、README 或镜像。镜像构建上下文通过 `.dockerignore` 排除 `.env` 和 `server/local_secrets.py`。

页面的“分析页面控件”首次使用前会征求同意；只发送控件名称和位置图，不包含摄像头画面或输入框内容。配置密钥时，该控件图会转发给 MiMo。AI 接口在 JSON 解析前对完整请求体（包括分块传输）限制为 5 MB，解码图像限制在 1920×1080 像素。Nginx 按来源地址限制每分钟 30 次，应用另有限流并将来源表限制为最多 10000 条；扩容多 worker 前须改用共享限流存储。

应用会附加 Content-Security-Policy、Referrer-Policy、X-Content-Type-Options、X-Frame-Options 和 Permissions-Policy；Nginx 在 HTTPS 响应上开启 HSTS。

## 临时 Cloudflare Tunnel

先用 `DDK_DEPLOYMENT_MODE=public` 启动本机网页服务，再运行 `外网演示.bat`。脚本会先检查健康接口，并在服务不处于公网模式或系统控制未关闭时拒绝开放隧道。公网模式不能同时用同一个进程做本机完整控制演示。

## 健康检查与常见问题

```powershell
Invoke-RestMethod http://127.0.0.1:8787/api/health
```

| 现象 | 处理 |
|------|------|
| 摄像头未出现 | 用 Chrome/Edge；允许站点使用摄像头。公网必须使用 HTTPS。 |
| MediaPipe 模型加载失败 | 检查 `static/models/` 文件随部署包存在，刷新后重试。 |
| 公网选择本机系统光标失败 | 这是预期行为；公网模式不会开放服务端鼠标/键盘。 |
| MiMo 不可用 | 检查服务器环境变量 `QWEN_API_KEY` 与出站 HTTPS；失败时会退回本地形状检测。 |
| AI 请求返回 413/429 | 控件图超出大小上限或请求过密；稍后再试。 |
| 手机/浏览器不能开麦 | 查看浏览器语音支持与权限；也可直接点页面按钮或键盘操作。 |
