# 动动口 · 用户体验走查报告

> **历史记录，已被后续产品决策取代。** 本报告记录早期方案与旧版问题，不代表当前交互要求。当前采用自由移动光标、到位直接点击；吸附不是点击条件。请以 `PRODUCT.md`、控制台现行 UI 与 `docs/superpowers/plans/2026-09-28-dongdongkou-overhaul.md` 为准。

> 走查身份：普通用户（非开发者）  
> 走查路径：打开首页 → 进控制台 → 开摄像头/校准/头控张嘴 → 语音 → 演示站（资讯/购物/预约）→ 架构页  
> 范围：交互、按钮、文案、加载、报错、路径、视觉、误解点（不改底层架构）

## 1. 用户完整操作流程（逐步感受）

### ① 打开首页 `/`
- **看到**：Hero、三大亮点、为谁而做、演示视频占位  
- **感受**：故事清楚，但「下一步点哪」不够强制；视频是空按钮，点了才发现是占位，有点空  
- **疑问**：我是残障用户/评委，为什么要信你？

### ② 点「进入控制台」
- **看到**：侧栏一长串开关（磁吸/张嘴/眨眼/灵敏度/平滑…）+ 中间摄像头  
- **感受**：像开发者仪表盘，不像「给老人/上肢不便者用的工具」；不知先开摄像头还是先校准  
- **疑问**：张嘴阈值 0.50 是什么意思？

### ③ 开摄像头
- **看到**：点「开启摄像头」→ 权限弹窗 → 模型加载  
- **感受**：加载久时只有「正在加载模型…」，不知道要等多久、要不要重试  
- **别扭**：换到架构页再回来，以前要再点一次（已做自动恢复，但若浏览器要手势仍会懵）

### ④ 校准 / 移动光标
- **看到**：「开始校准」5 秒倒数  
- **感受**：倒数时若晃头，不知道失效了；恢复默认校准文案写「中心为 0,0」——用户不懂  
- **别扭**：曾出现光标钉在角落/只往下（已修），一旦复现用户会直接弃用

### ⑤ 张嘴点击
- **看到**：勾选「张嘴点击」，阈值 0.50  
- **感受**：不知张多大才触发；误触会慌；和「眨眼点击」并存更乱  
- **别扭**：成功点击只有涟漪，失败无「未点中」提示

### ⑥ 语音
- **看到**：芯片 +「开始聆听」  
- **感受**：芯片好用；但必须 Chrome/Edge 的提示只在点失败时 toast，易错过  
- **别扭**：「第2个」要先有目标列表，空列表时说话没反应

### ⑦ 演示站
- **资讯/预约**：还行；预约小按钮头控难度高  
- **购物**：原先只有 3 个假商品，**和「天猫」无关**——黑客松叙事弱（本次已补天猫入口）  
- **别扭**：「重置场景」全局重置，误点丢进度；无确认

### ⑧ 架构页
- **感受**：评委友好，普通用户像文档；从这里回控制台路径还行

## 4. 天猫购物（黑客松向）— 推荐方案

**目标**：在「模拟购物」里出现可信的天猫入口，**头控能进、能逛、能关、能回**，不要跳丢。

**为什么不直接 iframe 官网**：天猫/淘宝会拦 iframe（X-Frame-Options），头控也无法稳定点到站内真实小按钮。

### 方案（推荐，已实现）

1. **入口卡片**（购物场景顶部，≥56px 主按钮）  
   - 左：**天猫 Logo**（演示用矢量标，红底白猫头风格）  
   - 右：文案「天猫购物 · 免手逛店演示」  
   - 主按钮：**「进入天猫购物」**（`data-click`，可头控/张嘴）  
   - 次按钮：「在新标签打开天猫官网」（`window.open`，可选加分）

2. **应用内「天猫壳」**（全屏覆盖，像系统浏览器）  
   - 顶栏假浏览器 + 大关闭 **「返回演示站」**（右上/底部双入口，≥48px）  
   - 天猫风格红/橙色首页：搜索框、横幅、4–6 个**大商品卡**（可加购）  
   - Esc / 语音「返回」可关  
   - 全程仍在本站，头控模型不断线

3. **返回路径（多通道）**  
   - 头控/张嘴点「返回演示站」  
   - 语音「返回 / 关闭」  
   - 键盘 Esc（辅助人员）  
   - 可选：新标签真天猫后，回到本页点「我已回到演示站」

4. **Logo 说明**  
   - 演示用**自制天猫风格矢量标**（红底、简洁猫耳/猫脸），避免直接嵌官方受商标限制的位图；正式对外若需官方 Logo，应走天猫品牌授权素材。

## 5. 一句话结论

产品故事（无障 + 头控/张嘴 + AI）站得住，但 **首次使用的三步引导、张嘴安全感、失败可恢复、以及「天猫购物」可头控闭环** 决定评委和真实用户会不会觉得「别扭」；按上表 1–6 做完，体验会从「工程 demo」变成「能用的产品」。
