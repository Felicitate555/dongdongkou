# 动动口 · 作品提交资料

## 作品名称

动动口：头控与语音免手交互助手

## 作品介绍（500 字内）

动动口面向上肢活动受限者及需要降低鼠标、键盘使用负担的人群，以“转头移动、张嘴点击、语音辅助”完成电脑交互，对应科技无碍赛道。浏览器使用 MediaPipe 在本地识别人脸关键点，直接移动自由光标并点击当前位置，无需先吸附目标；可选 AI 分析页面控件结构图，辅助选择目标。产品保留两种模式：Windows 本机服务可显式开启系统鼠标与键盘控制；公网网页体验只操作演示页面，后端禁止控制云服务器。已实现资讯浏览、模拟购物与社区预约流程，部署于 https://dongdongko.fun/，无需安装即可查看网页演示。项目包包含源码、本地模型资源、启动说明和测试；购物、预约均为虚构示例，不创建真实订单或预约。

## AI 实践（300 字内）

本地端使用 MediaPipe Face Landmarker 识别人脸关键点，计算头部方向和张嘴动作；语音使用浏览器 Web Speech API。用户同意后，页面可见控件的名称和位置被绘制成结构图，由服务端调用小米 MiMo-V2.6-Flash 视觉模型识别可交互目标，并将归一化坐标转换回页面像素；无密钥、超时或结果无效时回退 OpenCV 本地形状检测。摄像头视频在浏览器或 Windows 本机线程内处理，不发送到云端；口动助手支持 MiMo 文字对话及用户确认后的屏幕截图分析，浏览器提供语音识别与朗读。SQLite 保存注册账号与文字对话，游客不落库，截图不持久保存。模型密钥仅存后端配置。

选择“其他”：MediaPipe Face Landmarker、小米 MiMo-V2.6-Flash、OpenCV、浏览器 Web Speech API。不要把小米 MiMo 写成通义千问。

## 体验路线

1. 打开 https://dongdongko.fun/ 了解两种模式。
2. 进入演示站：资讯详情、模拟购物加购→结算→完成、预约科室→时间→空白示例信息→确认→完成。
3. 头控体验需本人授权浏览器摄像头权限，面对屏幕校准；摄像头视频不上传。
4. Windows 本机版按 README 启动。用户手动开启后台控制后可操作其他软件，并使用摄像头/助手悬浮窗；该模式有全局 Esc 和持续闭眼暂停。兼容前台模式的网页 Esc 仍不是全局热键。
